# Tayriva 0.14.0

This release changes the native workbook format. Create or open a **.tay** workbook; earlier Gridloom SQLite and JSON workbooks are intentionally unsupported, even if renamed. Autosave starts in a new Tayriva recovery directory without touching older files.

Extract the full package. Launch **tayriva.exe** on Windows or **./tayriva** on Linux. The headless agent executable is **tayriva-mcp.exe** or **./tayriva-mcp**. See [installation](https://github.com/TayrivaHQ/tayriva/blob/v0.14.0/docs/INSTALL.md), [agent setup](MCP.md), and the [workbook guide](https://github.com/TayrivaHQ/tayriva/blob/v0.14.0/docs/WORKBOOKS.md).
